## Что действительно проверено до передачи

- 165 Node-тестов, TypeScript/Vue typecheck и production build.
- Восемь Chromium-сценариев, database CLI/API, автоматический backup с настоящим 60-секундным таймером и restart.
- .NET 10 locked build, 31 self-test, 32 process recovery и два API dry-run; переход сохранённого state net8→net10 без смены ID/повтора команды.
- Windows-пакет: десять проверок комплектности/повреждения; опубликованная managed DLL проверена в Linux. Это не запуск Windows EXE.
- Нагрузка: 52 вымышленных клуба/3380 ПК/100k завершённых jobs; отдельный 15-минутный профиль 600 heartbeat/с с тремя автоматическими копиями/restore/retention прошёл после исправления генератора. Первый неуспешный прогон сохранён. Профиль не равен опросу всех агентов раз в две секунды и не доказывает многочасовой SLA.

Проверки относятся к указанным блокам и исходникам; исторические JSON-отчёты и их SHA не переписывать под последующие изменения. Новый прогон передачи записывается отдельно в PROJECT-STATUS.

## Ближайший блок: первый запуск и диагностика Windows — ещё НЕ реализован

Пользователь сможет тестировать на личном ПК через два дня после текущего разговора. Версия Windows неизвестна. До этого полезно реализовать 4.43:

- [ ] 4.43.1. Read-only preflight: ОС/архитектура, .NET runtime, PowerShell/доступность NetQos, целостность пакета, понятный компактный отчёт. Без установки, изменения политики исполнения, служб, правил и UWF.
- [ ] 4.43.2. Отдельный локальный лабораторный запуск панели/API и агента на одном ПК без `--enable-qos`. Отдельная PILOT БД, личный администратор, ручной enrollment, HTTP только loopback. Не использовать публичные DEMO-аккаунты или менять обычный `npm run local` (он запрещает настоящих агентов).
- [ ] 4.43.3. Точная инструкция и шаблон результатов: self-test → регистрация → dry-run → история → stop/start → прежний ID/нет replay → штатное завершение. Отдельно записывать «не выполнялось», «не поддерживается» и фактическую ошибку.
- [ ] 4.43.4. Проверить понятность сообщений об отсутствии runtime, недоступном сервере, неверном config/состоянии. Добавлять код только по найденным пробелам; существующие защиты не отключать.
- [ ] 4.43.5. Подготовить ограниченный диагностический отчёт по разрешённым полям. Не включать identity/token/enrollment/config целиком, state, БД, packet capture, имена пользователей ОС и общий environment. Отчёт никуда автоматически не отправлять.
- [ ] 4.43.6. Выполнить доступные Linux/статические проверки, обновить инструкции и пакет при изменении его состава; фактическое исполнение Windows оставить непроверенным до стенда.

Критерий готовности блока: есть проверяемые команды и файлы для одного личного тестового ПК, пользователь понимает результат каждого шага. Реальная установка/запуск на его ПК, Windows QoS и публикация не входят в облачную подготовку.

Работа маршрута и симптомов в клубе проверяется отдельно. Ни один из этих пунктов не закрывается dry-run.

## Передача исходников и запуск

Исходники/тесты/документы/lockfiles отправляются в Git; `.data`, БД, токены/state, SDK, node_modules, сборки, логи и бинарные ZIP туда не входят. По новому поручению пользователя разрешён текущий push без force; Actions пропускаются через `[skip ci]`. Публикации сервиса это не разрешает.

Панель DEMO: `npm ci`, затем `npm run demo`. Личный владелец: `npm ci` → `npm run setup:owner` → `npm run local`. Оба режима работают только на loopback и не принимают настоящий агент. Детали — [README](../README.md), [LOCAL-OWNER](LOCAL-OWNER.md).

Windows ZIP можно заново собрать из репозитория по [WINDOWS-PACKAGE](WINDOWS-PACKAGE.md) / [README](../README.md). Файлы `/workspace/paneltech-agent-win-x64.zip` и `/workspace/paneltech-local-source.zip` принадлежат текущей облачной среде и могут отсутствовать в новом чате; их наличие нельзя предполагать. SHA существующего лабораторного Windows ZIP: `a97a4c698d0d34c47af3ba97432644b5b3080219df0aa9ccfb4d46d3f744bf7a`.

Не добавлять вне текущего ТЗ: FACEIT, Telegram-бот, загрузки игр, автоматический подбор маршрута, удалённый произвольный shell, управление UWF и автоматические перезапуски игр/ПК.
