## «25 приёмов дизайна»: применимое и отложенное

| Приёмы / страницы | Решение и применение |
| --- | --- |
| 1–4,7 / 3–5 | Единая проектная дизайн-система и навык полезны: создан DESIGN.md и paneltech-ui-review. Не копировать чужой бренд и не переделывать приложение в три стиля без задачи на редизайн |
| 5 / 4 | Шрифтовая иерархия полезна; документирован реальный системный fallback. Новый web font/CDN не добавлен; нужна лицензия и необходимость |
| 6,12 / 4–5,7–8 | Конкретные русские тексты действий/ошибок, без автоматических обещаний «пинг исправлен». Не выдумывать исследование конкурентов или tone of voice по несуществующим примерам |
| 8 / 6,8 | Kie.ai — платная media-интеграция, не требуется. Пример с API-ключом не переносить в чат/файлы; ключи только через защищённые настройки при отдельной задаче |
| 9–10 / 6,8 | Повторно использовать существующие компоненты и осмысленно разбирать референсы. Нет доступа к произвольным прошлым сессиям/проектам; не заявлять, что они изучены |
| 10+ / 7,11 | Browser extension из Google Drive не устанавливалось; локальный DESIGN получен из собственного CSS, без расширения и чтения чужих страниц |
| 11 / 7 | Impeccable изучен: hierarchy/operate/edge cases/visual QA адаптированы в проектный навык; launcher/hooks не установлены |
| 13–15 / 9 | 21st.dev, React Bits, Canvas UI — ресурсы компонентов/эффектов, не обязательные skills. React-код не переносить прямо в Vue; эффекты не оправдывают лишнюю зависимость |
| 16–18 / 9–10 | SVG и единый набор иконок подходят для будущей правки; Iconify/Flaticon/Lordicon требуют проверки конкретной лицензии/формата. Ничего не скачивалось и не покупалось |
| 19 / 10 | Creators Toolbox — каталог для целевого поиска, не основание установить все ресурсы |
| 20 / 12,14 | Читаемость, знакомые controls и доступность полезны. Не выдавать web-панель за Apple HIG-compliant без аудита; не придумывать точные HIG-нормы. Критерии проверки в DESIGN явно отделены от текущего соответствия |
| 21 / 12 | Полезное движение по задаче и reduced motion; GSAP не добавлен ради простых переходов |
| 22–23 / 12–13 | /design и /tweak относятся к конкретному продукту/клиенту; не создавались фиктивные команды Codex |
| 24 / 13 | HyperFrames прочитан как будущий инструмент ролика; видео сейчас не требуется |
| 25 / 13–14 | Небольшой индекс навыков и отчёт созданы. Отдельное веб-приложение «дизайн-студия» не входит в текущую задачу |

Основной вывод для PanelTech: оператору нужны предсказуемые действия, понятные статусы, контраст и плотные читаемые таблицы. Рекламные hero, фоновые видео и сложный скролл могут ухудшить эту задачу.
