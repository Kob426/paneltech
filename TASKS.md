# Этапы и подзадачи PanelTech

План актуализирован после сверки файлов проекта и Git 22 октября 2026. Текущий рубеж: **локальный функциональный DEMO реализован; следующая работа — сохранить проверенную версию и стабилизировать её перед Windows-проверками**. Процент общей готовности не оценивается: системные проверки Windows/MikroTik ещё не выполнены.

Статусы: `[x]` — выполнено с указанной границей проверки; `[ ]` — открыто. Результаты прежних запусков перечислены в PROJECT-STATUS.md; при этой актуализации плана тестовые наборы повторно не запускались.

## Этап 5. Windows-лаборатория — внешняя предпосылка

Зависит от этапа 4 и наличия отдельно согласованной тестовой Windows-машины/VM с повышенными правами. Не использовать рабочие клубные ПК по умолчанию.

- [ ] 5.1. Перевести агент на поддерживаемый LTS .NET и повторить build/контрактные проверки; текущий .NET 8 заканчивает поддержку в ноябре 2026.
- [ ] 5.2. Проверить win-x64 publish, состав пакета, Windows PowerShell 5.1 и требования code signing/execution policy.
- [ ] 5.3. Проверить консоль и SCM-службу: старт/стоп/удаление, один процесс, service account и ACL state/config/binary.
- [ ] 5.4. Выполнить inspect/apply/repeat/switch/remove с фактическим чтением NetQos ActiveStore; проверить сохранность других игр и сторонних политик.
- [ ] 5.5. Проверить GPO, wildcard/пути, общие exe, отсутствующие cmdlet и недостаточные права.
- [ ] 5.6. Воспроизвести частичный отказ, неуспешный откат, crash/потерю ответа и boot-change; зафиксировать остаточные изменения и процедуру ручного восстановления.
- [ ] 5.7. Проверить TLS/доверие сертификатов, часы и постоянное хранение identity/token/manifest. UWF не отключать и исключения автоматически не менять.
- [ ] 5.8. Оформить Windows-протокол проверки с версиями ОС/PowerShell, командами и фактическими результатами.

Условие завершения: подтверждена системная работа агента на тестовой Windows. Это ещё не проверка маршрута конкретного клуба и не разрешение на распространение.
